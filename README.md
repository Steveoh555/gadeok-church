# 가덕교회 홈페이지

부산 가덕도 가덕교회(1905년 설립)의 홈페이지입니다.

**주소** — https://steveoh555.github.io/gadeok-church/

## 구성
- **홈** — 2026 말씀의 여정(52주 모자이크), 이번 주 말씀, 최근 설교, 새벽기도, 교회 소식, 예배 안내, 가덕선교마을 지도
- **설교방송** — 유튜브 주일예배 실황 다시보기
- **주보** — 주간 주보 보기와 내려받기
- **성경공부** — 가정예배교재(빈칸을 눌러 답 확인)
- **교회소개** — 예배 안내, 섬기는 사람들, 오시는 길

## 안내
정적 웹사이트라 별도 서버가 필요 없습니다. 주보 자료는 교회 내부에서 관리하는
도구로 매주 갱신하며, 이 저장소에는 갱신 결과(`js/data.js`)만 올라갑니다.

주보에 교인 정보가 포함되어 있어 검색엔진 수집은 `robots.txt`로 막아두었습니다.
